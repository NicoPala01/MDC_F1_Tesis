# MDC_F1_Tesis

Repository corresponding to a master thesis project focused on data analysis,
clustering, and modeling applied to Formula 1 driving and performance
metrics. The main objective is to explore driving patterns and
performance characteristics using data science and machine learning
techniques.

## Objectives

-   Analyze datasets related to motorsport driving and performance.
-   Apply clustering techniques to identify driver profiles or patterns.
-   Explore relevant metrics and their relationship with performance.
-   Develop reproducible analysis workflows using notebooks.


## Technologies Used

-   Python
-   Jupyter Notebook
-   Virtual environments (venv)
-   Main library:
    -   FastF1
-   Common data science libraries:
    -   pandas
    -   numpy
    -   matplotlib
    -   scikit-learn

## Installation

Clone the repository:

    git clone https://github.com/NicoPala01/MDC_F1_Tesis.git
    cd MDC_F1_Tesis

Create a virtual environment (recommended):

    python -m venv .venv

Activate the environment (Windows):

    .venv\Scripts\activate

Install dependencies:

    pip install -r requirements.txt
